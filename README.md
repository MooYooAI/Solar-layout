# 태양광 배치 설계

지번으로 필지를 찾고, 지적도 위에 태양광 모듈을 가배치하고, 계절별 음영과 발전량을 확인하는 웹 도구입니다.

## 작업 흐름

왼쪽 단계 메뉴는 6단계입니다: **현장정보**(부지·지형·가설계) → **기본설계**(배치·전기·음영·발전량, 끝에서 설계 확정) → **도면**(도면·내보내기) → **인허가**(필요 인허가와 진행 상황) → **경제성** → **발주**(기자재 물량·설치비 내역). 기본설계에서 확정한 설계가 뒤 단계의 기준이 되고, 확정한 뒤 배치나 설정을 고치려 하면 "설계 변경"을 먼저 묻습니다. 확정본은 이력에 남아 다시 불러올 수 있습니다. 프로젝트로 한 번 저장하면 그 뒤로는 고칠 때마다 저절로 저장되고, 단계마다 "들어올 때로"로 그 단계에 들어올 때의 상태로 되돌릴 수 있습니다.

## 진행 단계

1. **지번 검색과 지적도** (완료): VWorld 주소 검색, 연속지적도 표시, 필지 경계·면적·공시지가·용도지역 표시, 영역 직접 그리기, 사각형 수치 입력(가로·세로·회전), 옆 지번을 더해 여러 필지를 한 부지로 합치기, 용도지역 지도 레이어, 거리·면적 재기
2. **모듈 가배치와 수동 편집** (완료): 모듈 종류(규격대별 목록 또는 직접 입력)·세트 구성·경사각·방위각, 구조물(파일·콘크리트 기초·영농형), 패널 간격·세트 간격·열 이격거리(피치)·경계 이격 설정, 동지 기준 열 이격거리 추천, 자동 배치(한 방향 또는 구역별 방위각), 선택·이동·회전·추가·삭제, 되돌리기·다시실행(Ctrl+Z / Ctrl+Shift+Z)
3. **음영 분석과 발전량** (완료): 날짜·시각별 태양 위치와 그림자(세트 간, 건물·나무 장애물), 그늘진 모듈 비율, 월별·연간 발전량과 음영 손실
4. **경제성 검토** (완료): 설치비(kW당 단가 직접 입력 또는 설계 물량으로 산출), 판매 방식(고정가격 계약 또는 SMP+REC 현물, 용량·지목별 REC 가중치 참고값), 운영비·토지 임대료, 효율 감소, 융자로 회수기간, 자기자본·사업 IRR, NPV, LCOE, 누적 현금흐름, 융자 상환표 계산
5. **입지검토 보고서** (완료): 부지 개요, 벡터 배치도(동지 정오 그림자 포함), 배치 조건과 결과, 계절별 음영, 월별 발전량, 경제성을 한 장에 모아 인쇄하거나 PDF로 저장
6. **지형과 설계 가능 영역** (완료): 필지 표고를 자동으로 불러와 경사·절성토를 지도 색으로 표시하고, 경사 한도를 넘는 곳과 배수 경로(물길) 주변을 뺀 설계 가능 영역을 계산해 자동 배치·AI 설계가 그 구역을 피하게 함. 배치한 세트 자리의 토공량(구조물 방식별 허용 경사 반영)
7. **전기 설계** (완료): 인버터 종류·DC/AC 비율·모듈 전기 사양으로 직렬 장수, 스트링·인버터 묶음, DC·AC 케이블 경로·길이·규격·손실, 클리핑 손실, 저압/특고압 연계와 변압기 용량, 단선결선도 미리보기
8. **AI 설계와 배치안 비교** (완료): 경사각·방위각·피치·첫 열 위치를 바꾼 수십 가지 배치와, 경계 방향이 여러 개인 필지에서 구역마다 방위각을 달리한 배치·빈자리 채우기 안을 여러 워커로 동시에 평가(전기 설계, 음영·클리핑·케이블 손실 발전량, 토공량, 설치비, LCOE·IRR)해 "발전량 최대", "LCOE 최저", "균형", "효율 최대" 안을 고르고, 현재 배치·저장한 배치안과 한 표에서 비교
9. **내보내기** (완료): 배치도 DXF(국내 TM 좌표, 부지·등고선·제외 구역·물길·어레이·모듈·인버터·케이블 레이어), 단선결선도 DXF·SVG, CSV(어레이 목록, 스트링 결선표, 인버터·AC 케이블, 월별 발전량, 설치비 내역, 배치안 비교, 연도별 현금흐름)

## 바로 열기

`main`에 올라가면 GitHub Actions가 빌드해서 GitHub Pages에 배포합니다: https://mooyooai.github.io/solar-layout/

처음 한 번은 저장소 Settings > Pages에서 Source를 "GitHub Actions"로 바꿔야 합니다. VWorld 키는 Settings > Secrets and variables > Actions에 `VITE_VWORLD_KEY`로 등록하고(화면에는 키 입력 칸이 없습니다), VWorld 키의 서비스 URL에는 `mooyooai.github.io`를 추가해야 합니다.

## 로컬 실행

```bash
npm install
cp .env.example .env.local   # VITE_VWORLD_KEY 입력 (선택)
npm run dev
```

VWorld 인증키는 [vworld.kr](https://www.vworld.kr)에서 무료로 발급받고, 서비스 URL에 사용할 도메인(개발 중이면 `localhost`)을 등록하세요. 키가 없으면 OpenStreetMap 배경에서 영역을 직접 그려서 쓸 수 있습니다.

## 계산 방식

- 태양 위치: Cooper 적위, Spencer 균시차, 한국 표준시(동경 135°) 보정
- 그림자: 세트 경사면 네 꼭짓점과 장애물 윗면을 태양 반대 방향 지면으로 투영한 볼록 다각형. 모듈마다 경사면 위 두 점을 같은 방향으로 내려 다른 물체의 그림자 안에 들면 그늘로 본다. 세트가 많으면(실시간 250개, AI 설계 50~100개 초과) 고르게 뽑은 세트의 평균 음영으로 계산한다.
- 발전량: 한국 평균 월별 수평면 일사량 → Erbs 산란 비율 → Collares-Pereira & Rabl 시간 분배 → 등방성 하늘 모델 경사면 일사량. 그늘진 모듈은 직달 일사를 잃는다고 본다. 모듈 온도 손실을 켜면(기본) 필지에서 가까운 권역의 월평균 기온에 하루 기온 변화(±4°C)를 더하고, 셀 온도 = 기온 + (NOCT 45 − 20)/800 × 경사면 일사, 출력 = 1 + 온도계수(−0.35%/°C) × (셀 온도 − 25)로 15분마다 보정한 뒤 온도 외 손실 성능계수(기본 0.86)를 곱한다. 일사량은 아직 전국 평균값이다.
- 클리핑: 15분마다 DC 출력이 인버터 AC 정격 합계를 넘는 만큼 뺀다. 월평균 하루로는 한낮 봉우리가 뭉개지므로 맑은 날(평균의 1.35배)과 흐린 날(0.65배)이 반씩이라고 보고 따로 자른다.
- 지형: AWS 공개 표고 타일(Terrarium, 한국은 SRTM 약 30m 원자료)을 줌 15로 받아 쌍선형 보간한다. 필지 경사·절성토는 3m 격자에서 셀마다 표고와 경사·향을 구하고, 계획면을 최소제곱 평면(기울기는 최대 경사로 제한) 또는 수평면으로 두고 높이를 절토량=성토량이 되게 맞춘다. 개략 검토용이며 인허가·시공 물량은 측량 자료로 다시 산정해야 한다.
- 설계 가능 영역: 필지 주변 100m까지 3m 표고 격자를 만들고, 경사가 한도(기본 25%)를 넘는 셀과 물길 양쪽 이격(기본 3m) 안의 셀을 뺀다. 물길은 D8(가장 가파른 이웃 셀로 흐름) 집수면적이 기준(기본 5,000㎡)을 넘는 셀이다. 자동 배치는 세트 바닥을 1.5m 간격으로 훑어 제외 셀에 걸치면 그 자리를 건너뛴다.
- 세트 자리 토공량: 세트 바닥 1m 간격 표본에 평면을 맞추고, 기울기를 구조물이 따라갈 수 있는 한도(파일 남북 15%·동서 10%, 콘크리트 5%·5%, 영농형 10%·8%)로 줄인 뒤 기초로 흡수하는 요철(±0.3m, 콘크리트 ±0.1m)을 넘는 만큼을 절토·성토로 본다.
- 전기: 최저 기온(기본 −20°C)의 개방전압과 셀 70°C의 동작전압으로 직렬 장수 범위를 정하고, 남는 모듈이 1% 이하인 가장 긴 길이를 고른다. 인버터 대수 = 반올림(DC 용량 / (목표 DC/AC × 정격)). 세트를 열마다 지그재그로 이어 스트링을 만들고 이웃한 스트링을 인버터에 고르게 묶는다. 인버터는 묶음 가운데 세트 뒤, 수배전반은 인버터들 가운데에서 가장 가까운 부지 경계 위에 두고, 케이블은 세트 방향 축을 따라 ㄱ자로 잰다. AC 케이블은 허용전류(정격 전류의 1.25배)와 전압강하 3%를 만족하는 가장 가는 규격을 고른다. 정격 출력 기준 저항 손실의 60%를 연간 발전량 손실로 보고, 성능계수에 들어 있다고 보는 1%와의 차이만큼 발전량을 고친다. 100kW 미만은 저압, 이상은 특고압(22.9kV) 연계와 변압기로 본다.
- 설치비(설계 물량 산출): 모듈(원/W), 인버터(AC kW), 구조물(방식별 kWp 단가), 기타 전기, 설치 공사, DC·AC 케이블 길이(AC는 규격별), 절토·성토량, 계통연계(저압 고정 또는 특고압 고정 + 변압기 kVA), 설계·인허가·감리(직접비의 %)를 더한다. 단가는 시장 참고값이며 경제성 탭에서 고칠 수 있다.
- 경제성: 1년차 발전량에 해마다 효율 감소를 곱하고 판매 단가로 매출을 낸 뒤 운영비와 원리금을 뺀 자기자본 현금흐름으로 회수기간·IRR(이분법)·NPV를 구한다. LCOE = (설치비 + 운영비 현재가치 합) / 발전량 현재가치 합. 세금과 물가상승은 넣지 않는다.
- AI 설계: 경사각 10~35°(5° 간격), 방위각(정남, 필지 긴 변이 ±30° 안이면 그 방향), 열 이격거리(동지 무음영 거리의 50~120%, 최소 1m 통로)를 네 계절 1시간 간격 근사로 훑은 뒤, 기준별 상위 후보 주변(경사각 ±2.5°, 첫 열 위치)을 12개월 1시간 간격으로 다시 계산한다. 후보는 CPU 코어 수만큼 워커에 나눠 동시에 평가한다.
- 내보내기: 배치도 DXF는 R12(AC1009) 형식으로 경도에 맞는 국내 TM 원점(EPSG:5185~5188, GRS80) 평면좌표(m)를 쓴다. 한글은 `\U+XXXX`로 적어 CAD 코드페이지와 상관없이 보인다. CSV는 엑셀용 UTF-8(BOM)이다.
